# 第一版设计与接口说明

## 来源与工程边界

基础是已核对哈希的本届Lab3完整工程。MIPI接收、RAW10解包、去马赛克、官方AWB、DDR写读、PLL、HDMI发送和板级约束均保留。官方字体与安路Logo ROM原样复用。团队新增rtl目录中的控制、处理和OSD模块，替换显示混合器实例。Lab2作为算法参考；团队边缘实现使用独立验证的单像素Sobel，不直接复制其四像素/两采样点算法。

“原图”指官方ISP处理并从DDR读出的RGB视频，并非未处理的传感器RAW。

## 数据流

SC500CS → 两lane MIPI接收 → 40位RAW10（4像素/拍）→ 官方去马赛克/AWB → 96位RGB（4像素/拍）→ 128位存储打包 → DDR → 官方video_out → 24位RGB（1像素/拍）→ 团队增强/Sobel/选择 → OSD → HDMI发送。

新增处理全在HDMI_PIXEL_CLK域，不新增跨域算法数据。该域原报告约75MHz，1650×750总时序对应约60.606Hz，不能直接写成已实测标准60Hz。实际显示设备兼容性待上板；本次保留官方PLL配置，不擅改。

DDR读出每16个RGB像素跨3个128位数据字，高位先输出。原FIFO设置SHOW_AHEAD_EN=0、OUTREG_EN=NOREG。video_out在请求后两个采样沿向下游提供像素；适配器将DE/HS/VS同步延迟两级。已用原video_out RTL与同步读FIFO替代模型逐像素验证；FIFO替代模型不验证厂商真实FIFO、跨域、满空和DDR。

核心输入：clk/rst_n；de/hs/vs；x/y各12位；rgb[23:16]=R、[15:8]=G、[7:0]=B；mode=0/1/2；bright=0..4；contrast=0..2；edge_level=0..4；selected标记。输入每时钟一个像素，de=0为空闲；没有ready信号，不支持下游暂停。摄像头端所谓AXI命名接口没有因此被假设成完整AXI握手。

RAW10解包器先将组内P0/P1/P2/P3写到[39:30]/[29:20]/[19:10]/[9:0]，输出时反序，因此送入demosaic的P0在[9:0]、P3在[39:30]。data128_96再次调整像素组排列，存储器显示方向最终仍以实物测试确认，不能从RAW位段名直接假定屏幕左右方向。

顶层外部I_rst_n通过PLL复位，锁定信号驱动内部低有效复位。新模块用异步置复位；释放行为沿用基线，完整复位跨域安全性仍需审查和实板验证。原video_out接收的是反相S_video_out_vsync，团队mixer接收未反相S_hdmi_vsync，两者不能直接互换。

像素算法从输入采样沿n到输出沿n+4，所有坐标、同步、参数元数据同延迟；OSD再寄存一级。适配器外部输入控制到输出共8次寄存采样（输出沿为输入沿+7）。数据流测试检查了每拍DE/HS/VS，而不只检查最后一张图。

## 算法精确定义

增强对R/G/B每个8位通道分别计算：

`out = clamp(floor((in - 128) * k / 4) + 128 + offset, 0, 255)`

k依次为3、4、5，offset为-32、-16、0、16、32。先绕128调整对比度，再加亮度，最后限幅；负数采用向负无穷舍入。该方法不是自动曝光，不声称保持色相；高亮/暗部限幅可能损失细节。标准对比度、零偏移为逐位恒等变换。

边缘灰度为`floor((R+2G+B)/4)`，范围0..255。在完整水平分辨率上应用3×3 Sobel，强度为`abs(Gx)+abs(Gy)`，阈值取40、80、160、320、640（默认160）。这组阈值覆盖由细节到强轮廓的演示范围，数值正确性已测，真实场景效果到板后校准。

Gx/Gy各在-1020..1020之间；8位灰度窗口可达到的L1强度上限1530（合并两个核的正权重总和为6），使用12位幅值寄存器留足余量。阈值比较为“大于等于”。阈值不是亮度值，也不是百分比；越高通常只留下越强的轮廓。

因采用因果窗口，输出坐标(x,y)使用[x-2..x]×[y-2..y]窗口，其几何中心是(x-1,y-1)：轮廓相对原图向右下约一像素。前两行、前两列强制黑色。第一版只独立显示边缘，不叠加到原图；未来左右比较或轮廓叠加必须补偿该位移。两行缓冲不复位清空，前两行屏蔽并逐行覆盖，避免推导成大量寄存器。

## 控制与实际按键的区别

逻辑四键已实现：K1模式；K2增强参数选择；K3减；K4加。同步后稳定约10ms触发，持续按下不重复，释放稳定后再次按下才触发。冲突优先级：模式>选择>调节；同时加减互相抵消。复位恢复原图、亮度0、对比度1、阈值160。

待生效参数与当前显示参数分开保存，在输出场同步上升沿的消隐期提交。同一个时钟上的新按键事件在再下一个提交沿生效；消隐到有效画面间有足够时间。模式切换保留参数。

当前官方约束只提供I_button[0]=N2、I_button[1]=J14，两者连接到ae_set。原理图未取得，不能视为四个独立用户键。候选整板工程将逻辑键固定为未按下，AUTO预览定时循环模式，不占用现有曝光控制引脚。完整四键部署仍未完成，不得据此报告实板交互已实现。

OSD保留原始160×160 Logo；右侧两行显示模式、BR和CT或TH。BR用M/P表示负/正，CT显示075/100/125，黄色标记选中参数。AUTO字样只用于自动预览构建。
